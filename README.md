# Djerelo — Gulp Homework Project

Static front-end layout project updated for the Gulp lesson homework.

The project uses **Gulp** to automate routine development tasks: SCSS compilation, live reload, vendor prefixes, readable CSS output and minified CSS output.

## Technologies

- HTML5
- SCSS / CSS3
- JavaScript
- Gulp
- BrowserSync
- Autoprefixer
- CleanCSS
- Google Fonts (`Raleway`)
- Font Awesome

## What Gulp Does

The configured Gulp tasks provide:

- **SCSS compilation** — `src/scss/style.scss` is compiled into CSS.
- **Live reload** — BrowserSync refreshes the browser when HTML, SCSS, JS or image files are changed.
- **Vendor prefixes** — Autoprefixer adds browser-specific prefixes according to the `browserslist` settings in `package.json`.
- **Readable CSS output** — `dist/css/style.css` is generated in expanded format.
- **Minified CSS output** — `dist/css/style.min.css` is generated for optimized final usage.
- **Build folder generation** — HTML, JS, images and compiled styles are placed into `dist/`.

## Installation

Install project dependencies:

```bash
npm install
```

## Development Mode

Run the development server with live reload:

```bash
npm run dev
```

This command builds the project into `dist/` and starts BrowserSync at:

```text
http://localhost:3000
```

## Production Build

Create a fresh build without starting the development server:

```bash
npm run build
```

The generated files will be placed in:

```text
dist/
```

## Additional Commands

Remove the generated `dist/` folder:

```bash
npm run clean
```

Start only the BrowserSync server after a build:

```bash
npm run serve
```

## Notes

- Source files should be edited inside the `src/` folder.
- The `dist/` folder is generated by Gulp.
- `node_modules/` should not be committed to Git.
- The original project layout was preserved, but the project was reorganized into a more typical `src → dist` Gulp workflow.
